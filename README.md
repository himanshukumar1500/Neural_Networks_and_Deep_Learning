# Neural Networks and Deep Learning

A collection of hands-on implementations and experiments in Neural Networks and Deep Learning, developed as part of my engineering learning journey.

## 📌 Project Overview

This repository focuses on understanding deep learning concepts through practical implementation using Python. It includes machine learning experiments, neural network models, and projects designed to build a strong foundation in Artificial Intelligence.

## 🧠 Projects

### 1. MNIST Digit Classification
- **Objective:** Classify handwritten digits from 0 to 9.
- **Dataset:** MNIST handwritten digit dataset.
- **File:** `mnist_classification.ipynb`
- **Goal:** Understand image classification and neural network training.
